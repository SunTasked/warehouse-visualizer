# warehouse-visualizer

A warehouse operator traffic simulation and 3D visualization tool: simulate operator
movement under configurable WMS-style parameters, then visualize paths, congestion points,
and slot usage to find slotting/aisle-management optimizations.

See [specs.md](specs.md) for full project specs and [CONTEXT_LOG.md](CONTEXT_LOG.md) for
the session-by-session decision log.
